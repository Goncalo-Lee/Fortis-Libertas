# Planning

This directory contains the design and planning documentation for **Fortis Libertas**. It describes how the system was conceived before and during implementation.

## Directory Structure

```text
docs/planning/
├── api/            # API specifications and endpoint documentation
├── db/             # Database design, ER models, and data dictionary
├── ui/             # User Interface design system and component planning
└── ux/             # User Experience planning, sitemaps, and user flows
```

## Contents

- **[API Planning](./api/README.md)**: Details the REST API contract, including all endpoints, request/response formats, and business rules.
- **[Database Planning](./db/README.md)**: Contains the ER model, data dictionary, and visual schema diagrams.
- **[UI Planning](./ui/README.md)**: Describes the design system, typography, color palette, and component library.
- **[UX Planning](./ux/README.md)**: Outlines the sitemap, user flows, and interaction models.

## Philosophy

Planning at Fortis Libertas is a continuous process. While these documents serve as the initial blueprint, they are updated as the project evolves. The `planning/` directory is intended to be the "source of truth" for the intended behavior of the system.
