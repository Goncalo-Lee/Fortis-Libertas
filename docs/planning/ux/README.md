# UX Planning

This directory contains the User Experience planning for **Fortis Libertas**.

## Contents

- **[Sitemap](./sitemap.md)**: Hierarchical view of the application pages.
- **[User Flows](./user-flows.md)**: Diagrams and descriptions of key user journeys.

## Goals

1. **Efficiency**: Reduce the number of clicks required to log a new expense or income.
2. **Contextual Information**: Show relevant financial data (balance, upcoming bills) where the user needs it most.
3. **Security with Friction where Needed**: Ensure sensitive actions (changing 2FA, deleting accounts) are properly guarded without making the app unusable.
4. **Data Portability**: Allow users to easily navigate between dashboards and bank accounts they belong to.

## Target Audience

- Individual users looking to track personal finances.
- Families or small teams sharing a "Dashboard" to manage collective expenses.
- Users who require multi-currency support and exchange rate tracking.
